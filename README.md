JobLens AI
Resume-Based Intelligent Job Discovery Platform

JobLens AI is a full-stack, resume-driven job discovery platform that helps candidates find relevant job opportunities from multiple live job sources.

Instead of relying only on manually entered keywords, JobLens AI uses the candidate's uploaded resume to build a structured profile and generate personalized job-search queries. The discovered jobs are then normalized, verified, deduplicated, matched against the candidate profile, and intelligently ranked.

🚀 Live Demo
Live Application: https://joblens-frontend.onrender.com/

Upload a resume, build your candidate profile, and use Find Jobs to discover personalized opportunities.

✨ Key Features
📄 Resume-Based Profile
Upload a resume in PDF format.

Extract relevant information from the resume.

Build a structured candidate profile.

Store the active resume and candidate profile in PostgreSQL.

Update the active profile when a newer resume is uploaded.

🧠 Personalized Job Search
Search queries are personalized using:

Core skills

Supporting skills

Experience level

Preferred roles

Career keywords

Projects

Certifications

Requested location

🔎 Multi-Source Job Discovery
Current job sources:

Adzuna

Google Jobs through SerpAPI

Multiple personalized queries are searched across enabled providers in parallel.

Job Discovery

Normalization
      ↓
Verification
      ↓
Deduplication
      ↓
Resume Matching
      ↓
Intelligent Ranking
      ↓
Final Job Results
📊 Resume-to-Job Matching
Jobs are evaluated against the candidate profile so relevant opportunities can be surfaced based on the candidate's skills and background.

⚡ Persistent Job Results
Redux Toolkit and localStorage preserve search results while navigating:

Jobs → Job Details → Back to Jobs
Results can also remain available after a browser refresh until the user refreshes/clears them.

🔌 API Overview
Resume
POST /api/resumes/upload
Uploads and processes a resume.

Profile
GET /api/profile
Returns the active candidate profile.

Search Intent
POST /api/search/intent
Parses the user's search intent.

Search Plan
POST /api/search/plan
Creates a search plan from the search request.

Personalized Search Plan
POST /api/search/personalized-plan
Combines search intent with the candidate profile.

Job Search
POST /api/search/jobs
Discovers, processes, matches, and ranks jobs.
